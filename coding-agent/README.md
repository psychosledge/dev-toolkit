# coding-agent/

Claude Code / coding-agent assets intended to be copied into other repositories.

This subtree is intentionally separated from general dev utilities so it’s easy to:
- copy the entire `coding-agent/` folder into a project, or
- copy only specific skills/agents/commands.

## Subfolders
- `skills/` — skill definitions (each folder contains a `SKILL.md`)
- `agents/` — reusable agent prompt packs / role instructions
- `commands/` — scripts/utilities to support coding-agent workflows

## Intended usage
Copy any relevant folder(s) into the target project and tailor as needed.
