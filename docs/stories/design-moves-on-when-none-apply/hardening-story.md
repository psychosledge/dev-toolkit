# Unclear requirement answers get one clarifying question
Tier: core

## Summary

When this story is done, a developer whose answer to the unwritten-requirements question leaves a candidate's status unclear is asked once which candidates apply.

## Background

A partial or unclear reply, such as "approved, the first one maybe", leaves it open which candidates stay in the required-tests list.

## What needs to happen

- An unclear answer gets one clarifying question before the required-tests list is settled.

## Notes

- Follows `design-moves-on-when-none-apply`.
- Behavior-shaping, so skill-testing applies.

## Acceptance criteria

- A developer whose answer leaves a candidate's status unclear is asked once which candidates apply.
- A clear answer gets no clarifying question.
